# Aula 4

Este repositório contém os exercícios e práticas desenvolvidos na Aula 4.

## Objetivo
Continuar o estudo de algoritmos e programação, aprofundando conceitos fundamentais e resolvendo atividades práticas.

## Conteúdo
- Estruturas de controle
- Operações lógicas e matemáticas
- Vetores e estruturas básicas
- Exercícios aplicados

## Tecnologias
- C

## Como executar
1. Compile os arquivos em C.
2. Rode os programas em terminal.
3. Teste diferentes entradas para validar a lógica.
